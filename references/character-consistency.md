# Character Consistency

## Character lock
Record one canonical reference image and precise visible descriptors: face shape, hairstyle, approximate adult age, skin tone, outfit, accessories, voice and mannerisms. Use the same image reference for every scene where supported. Do not invent an identity from a text prompt alone.

## Scene generation
- Begin with a clean portrait/reference frame, then build each scene from that reference.
- Reuse the same identity and clothing descriptors verbatim.
- Keep product dimensions, color and details consistent with provided product photos.
- Specify gestures, expressions, background, lens, lighting and camera movement independently per scene.
- Avoid changing face, hairstyle, clothing, ethnicity, age, product form, logos or colors.
- Review every output side-by-side against the original; regenerate mismatches before editing.

## Limitations
Prompt text does not guarantee identity consistency. Reference-image and character-consistency controls depend on the generation platform.
